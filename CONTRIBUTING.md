

# 🧪 Contributing to SciMethod

Thank you for your interest in contributing to the SciMethod project! We welcome contributions that improve the system's usability, accuracy, and features.

## 🛠️ Getting Started

1. **Fork the repository** on GitHub.
2. **Clone your fork**:
   ```
   git clone https://github.com/yourusername/SciMethod.git
   cd SciMethod
   ```
3. **Create a virtual environment** and install dependencies:
   ```
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```
4. **Set up your `.env` file**:
   Create a `.env` file at the project root. Use `.env.example` as a template.

5. **Run the development server**:
   ```
   python manage.py migrate
   python manage.py runserver
   ```

## 🧩 Contribution Types

- 🐞 Bug reports
- ✨ Feature suggestions
- 🧼 Code improvements and refactors
- 📚 Documentation enhancements

## ✅ How to Contribute

1. **Check the Issues tab** for open issues or create a new one.
2. **Create a new branch**:
   ```
   git checkout -b feature/your-feature-name
   ```
3. **Make your changes** and commit:
   ```
   git commit -m "Add: [Your summary here]"
   ```
4. **Push and submit a Pull Request (PR)**:
   ```
   git push origin feature/your-feature-name
   ```
   Then open a PR against the `main` branch on the original repository.

## 💡 Guidelines

- Follow existing code style and naming conventions.
- Test your code before submitting.
- Use descriptive commit messages.
- Each PR should ideally address a single issue.
